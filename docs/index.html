今天這個戰情室要完成什麼？

值班人員只要完成四件事：找出最優先邊坡 → 看懂原因 → 建立巡檢任務 → 回填結果讓系統記住並學習。

1
先看「巡檢優先清單」不用先研究整張地圖；系統先把需要處理的邊坡排好順序。
2
在 3D 地圖確認位置點選清單或地圖紅橘點，確認工務段、路線與空間位置。
3
右側看「為什麼＋怎麼做」系統列出分級、熱點與歷史記憶，再給 P1–P4 處置建議。
4
巡檢後回填確認異常、誤報、已改善或持續觀察，會改變下一次巡檢優先分。

目前 MVP 的「學習」：同一處邊坡若被確認異常、誤報、改善或持續觀察，系統將其歷史回填轉成優先分校正量。這讓評審可以立即看到「回填前」與「回填後」的決策差異。未來取得真實 TP/FP/FN/TN 後，再替換為 Logistic / XGBoost + SHAP，不把 MVP 分數誤稱為災害機率。
真正的創新不是 3D：3D 只負責空間確認；核心是「人做完一次巡檢後，這次經驗會被保存並影響下一次排序」。
