# RailSafe Week 1 — source-only publication

First-week deliverables: TRA-02/03 data dictionary, candidate crosswalk, field-pilot shortlist and reproducible ASF Sentinel-1 IW SLC catalog search.

**Safety and license limits:** No TRA competition raw data or row-level candidate matches, validated coordinates, credentials, actual SLC imagery, or rail control code are committed here. The internal review workbook and candidate link lists are only distributed privately. Candidate overlapping track mileage is **not** proof of identical slope assets.

`asf_sentinel1_catalog.py` produces **catalog metadata only**, not InSAR deformation maps. The regional default bounding box is illustrative, not a certified asset footprint. Run with network access and review scene pairing before any HyP3 request.

See the accompanying internal W1 engineering report for numerical QA and unresolved CRS/identity gates.
